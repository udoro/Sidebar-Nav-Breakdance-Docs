# Documentation

**Sidebar Navigation Builder for Breakdance** is a header template for Breakdance. It gives you a sidebar menu with sliding panels, dropdowns you can nest, a collapsible mode, an off-canvas mode, a top bar and a mobile menu.

This documentation covers version **3.0.3**.

***

## What's included

| Part | What it is |
| --- | --- |
| [Header template](getting-started.md) | The Breakdance header template you paste into the builder. |
| [AI Connector](ai-connector/README.md) | Lets an AI agent build and edit your sidebar for you. |

## What it can do

* **Sliding panels.** A button opens a new panel that slides in, with Back and Home buttons. You can go as many levels deep as you like. Three levels is plenty for most menus.
* **Dropdowns.** Lists that open in place. You can put dropdowns inside dropdowns.
* **Collapsible sidebar.** Shrinks the sidebar to its icons, with tooltips.
* **Off-canvas, push content and top bar.** Hide the sidebar behind a menu button, push the page aside, or add a bar across the top.
* **Headroom.** The top bar hides when you scroll down and comes back when you scroll up.
* **Left or right.** Put the sidebar on either side of the page.
* **Keyboard and screen readers.** Tab, Enter and Escape work, panels have labels, and focus outlines show.
* **Normal Breakdance elements.** Everything is built from Breakdance elements, so you can change text, links and icons in the builder like anything else.

***

## How you customize it

You change the sidebar in three places:

1. **JavaScript options** in the **JavaScript** field of the **Sidebar Nav Codes** Code Block. These turn features on and off, such as the collapsible sidebar or off-canvas mode. See [Sidebar Options](sidebar-options.md).
2. **CSS variables** in the **CSS** field of the same Code Block. These set colors, sizes and spacing. See [Styling](styling.md).
3. **Attributes** on the **Sidebar &lt;header&gt;** section, the top element of the template. See [Attributes & Classes](attributes-and-classes.md).

### Change an attribute

1. In the builder, select the **Sidebar &lt;header&gt;** section in the Structure panel.
2. Open **Advanced**, then **Attributes**.
3. Find the attribute by its **Name** and change its **Value**.

The attributes are already on the section. To turn one off, clear its **Value** and leave the attribute where it is, so you can turn it on again later.
